# Recommendation model for e-commerce store (travel)

Client industry: travel  
Completed: 2024-03-14

## Brief
Recommendation model for e-commerce store.

## Approach
Main stack: Python, Docker. I chained prompts, retrievers and output parsers with an LLM orchestration library. I exposed it through an async Python web API with typed request schemas.
