# Fine-tune an LLM for ticket triage (legal)

Client industry: legal  
Completed: 2024-01-11

## Brief
Fine-tune an LLM for ticket triage.

## Approach
Main stack: Hugging Face, scikit-learn. I set up experiment tracking, a model registry and automated retraining. I exposed it through an async Python web API with typed request schemas.

## Outcome
The delivered system reduced cloud costs by 27%.
