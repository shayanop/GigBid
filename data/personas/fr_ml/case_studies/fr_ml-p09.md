# Deploy ML model behind FastAPI (manufacturing)

Client industry: manufacturing  
Completed: 2022-08-28

## Brief
Deploy ML model behind FastAPI.

## Approach
Main stack: Python, Hugging Face, RAG. I built a cross-validated gradient-boosted baseline with feature pipelines. I exposed it through an async Python web API with typed request schemas.

## Outcome
The delivered system saved the team 15 hours a week.
