# LangGraph agent for invoice processing (healthcare)

Client industry: healthcare  
Completed: 2024-01-19

## Brief
LangGraph agent for invoice processing.

## Approach
Main stack: scikit-learn, Python. I set up experiment tracking, a model registry and automated retraining. I modelled the agent as a stateful graph with checkpoints and human approval steps.

## Outcome
The delivered system cut processing time by 44%.
