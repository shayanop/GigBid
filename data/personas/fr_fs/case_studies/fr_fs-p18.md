# Django REST API for marketplace (travel)

Client industry: travel  
Completed: 2023-01-30

## Brief
Django REST API for marketplace.

## Approach
Main stack: AWS, Next.js, Celery, Tailwind CSS. I put an in-memory cache and rate limiter in front of the database. I used a batteries-included Python web framework with its admin and ORM.

## Outcome
The delivered system saved the team 16 hours a week.
