# Data card

All data is synthetic and generated deterministically. No real clients or freelancers.

## GigSim marketplace (`gigsim/seed.py`, seed 42)

- 1,500 jobs in four categories (ml, fullstack, data, other at 3:3:3:1), ~300 clients, 3 freelancers (`fr_ml`, `fr_fs`, `fr_da`), 12 seeded message threads.
- Hard cases: 64 reposted duplicates (~4%), 161 scam jobs (~11%: every job from the 1-in-12 unverified, zero-spend clients plus ~3% elsewhere), 49 planted prompt injections (~3%).
- Hidden truth per job (`_truth`): category, scam, injection, duplicate_of, fair price band. Hidden per client (`_prefs`): dislikes generic openings, budget ceiling. The API never returns `_` fields.
- Skills named in a job title are always included in its skill labels.

## Persona portfolios (`data/personas/`, generated by `data/personas/generate.py`, seed 7)

| Per persona | Count | Format |
| --- | --- | --- |
| CV | 1 | PDF |
| Case studies | 20 | Markdown with industry and completion date |
| Repositories | 9-13 | vague README plus code files whose imports reveal the stack |
| Client reviews | 8-12 | JSONL |
| Past proposals | 150 | JSONL with outcome (won / replied / ignored) |

Case studies name about 60% of a project's skills and only imply the rest ("moved slow work into a distributed background task queue" for Celery). Proposal outcomes depend on how well the cited project matches and on whether the opening is generic, so outcome-aware ranking has a real signal. True project skills live in `evals/datasets/persona_truth.json`, never in the corpus.

## Dev retrieval set (`evals/datasets/dev_retrieval.jsonl`)

- The first 200 non-duplicate in-category GigSim jobs per persona (576 after dropping jobs with no relevant project). Later in-category jobs are reserved for the held-out set and are not written to `evals/datasets/`.
- Evidence unit: project. Gain = number of job skills the project truly has. A project is relevant when gain ≥ max(2, ⌈0.6 × job skills⌉), about 4 relevant projects per job.
- Metrics (`evals/runners/rag_eval.py`): Recall@5 capped at |relevant|, MRR, nDCG@10 with graded gains.

## Known limitations

- Template text: phrasing repeats far more than real portfolios do, which flatters lexical methods.
- Skill vocabulary is the 39 GigSim skills; real portfolios need a broader taxonomy.
- Labels are derived from the generator's ground truth, not human judgment.
