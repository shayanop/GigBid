# GigBid

A freelancer's copilot built from LangGraph agents. It scouts jobs on a simulated
marketplace (GigSim), decides whether to bid, drafts proposals where every claim is backed
by the portfolio, and waits for your approval before anything is sent.

Sign in with the demo account given with the submission. The marketplace is simulated:
nothing reaches a real client. Data resets when the Space restarts.
